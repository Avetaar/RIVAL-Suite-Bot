# RIVAL Suite Bot
**الإصدار:** 0.1  •  **المطوّر:** Avetaar  •  **الفريق:** Rival

---

## العربية

مساعد ذكي على التلغرام، كله بأزرار — تضغط بس، ما تحتاج تكتب أوامر. بوت واحد يخدمك بكل شي: محادثة، صور، صوت، موسيقى، ترجمة، كله في مكان واحد.

### شنو بدالك
- 💬 محادثة — اسأل عن أي شي، اكتب، ناقش
- 🖼️ صور — امل صورة خيالك، عدّلها، شيل الخلفية
- 🔊 صوت — حوّل النص لصوت واضح
- 🎵 موسيقى — ولّد أغنية بأي نوع تبيه
- 🌐 ترجمة — 18 لغة، البوت يشوف اللغة ويترجمها تلقائي
- 📊 73 نموذج جاهز لكل هاي الخدمات
- 📎 النتيجة توصلك ملف جاهز (صورة أو صوت)، مو بس رابط
- 🔒 حماية ذكية: مستخدم غير مسموح له أو بوت مغلق تنحظر تلقائي
- 🔁 تعافٍ ذاتي: لو انقطع الاتصال يعالج نفس فورا
- ⚙️ لوحة تحكم للمالك: فتح/إغلاق، حظر، مسح البيانات، تحكم كامل
- 🏃 يشتغل على: Termux، لينكس، ماك، ويندوز، أي استضافة

### التثبيت — أمر واحد
حمّل الملفات، افتح الطرفية (الترمينال) بجوار فولدر البوت، وشغّل:

**Termux / لينكس / ماك:**
```
./install.sh
```
**ويندوز:**
```
install.bat
```

راح يسألك 3 أشياء:
1. توكن البوت
2. يوزر البوت (بدون @)
3. أيديك بالتلغرام (المالك)

بعد كذا البوت يشتغل لحاله. التوكن يخلص بمفصل منفصل مو بالكود — خلّه سرّي، لا تشاركه ولا ترفعه مكان.

**الإيقاف:** Ctrl+C
**تشغيل ثاني:** شغّل نفس الأمر مرة ثانية، أو `python Avetaar.py`

## English

A smart assistant on Telegram, all buttons — you just tap, no commands to type. One bot for everything: chat, images, voice, music, translation, all in one place.

### What you get
- 💬 Chat — ask anything, write, talk it out
- 🖼️ Images — make the image in your head, edit it, remove the background
- 🔊 Voice — turn text into a clear voice
- 🎵 Music — generate a song in any style you want
- 🌐 Translate — 18 languages, it spots the language and translates on its own
- 📊 73 ready models across all of this
- 📎 Results arrive as ready files (image or audio), not just links
- 🔒 Smart protection: not-allowed users and a closed bot get blocked automatically
- 🔁 Self-healing: if the connection drops, it fixes itself right away
- ⚙️ Owner panel: open/close, ban, wipe data, full control
- 🏃 Runs on: Termux, Linux, macOS, Windows, any hosting

### Install — one command
Download the files, open a terminal next to the bot folder, and run:

**Termux / Linux / macOS:**
```
./install.sh
```
**Windows:**
```
install.bat
```

It will ask three things:
1. Your bot token
2. The bot username (without the @)
3. Your Telegram ID (the owner)

After that the bot runs on its own. The token is stored in a separate file, not in the code — keep it private, never share it or upload it.

**Stop:** Ctrl+C
**Run again:** rerun the same command, or `python Avetaar.py`
